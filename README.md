# 星际跃迁 Star Hop

单击起跳的 HTML5 星球游戏，支持桌面鼠标与手机触屏。当前提供三十个闯关关卡和无尽挑战，无后端、无外部资源。

## 下载试玩

点击仓库页面 Code → Download ZIP，解压后用浏览器打开根目录 index.html。也可进入 index.html 文件页，选择 Download raw file 下载单文件，离线打开即可。无需 Node.js 或电脑持续运行。

## 1—10关

1. 初次起跳
2. 两次跃迁
3. 自由选路
4. 引力绕障
5. 移动终点与交会预判
6. 90° 传送门
7. 星球逐渐变小
8. 限时起跳
9. 钥匙解锁
10. 传送与限时组合

闯关以抵达终点为目标，不设星级评分；随机出现的星星用于兑换额外挑战机会。PERFECT 为精准操作反馈。第一关显示点击引导，其余通过图形展示；无键盘快捷键。无尽模式保留计分、连击和本地最高纪录。

## 开发与验证

使用 Node.js 重建：`node build.cjs`。

运行验证：

```
node tests/review.cjs
node tests/mobile-size.cjs
node tests/minimal-ui.cjs
node tests/next.cjs
node tests/third.cjs
node tests/twins.cjs
node tests/economy.cjs
```

可选本机服务：`node server.cjs`，访问 http://127.0.0.1:8095 。

`src/review-data.js` 定义关卡，`src/levels-engine.js` 实现可独立测试的模拟，`src/review.js` 处理绘制和交互。新增关卡可继续扩展数据；目前为三十关版本，尚未完成比赛所需五十关。

本地记录存储于浏览器，暂停菜单可导出试玩记录；不向服务器发送。已完成三十关路线、手机尺寸及界面自动检查，实体手机兼容性仍需实际试玩确认。

## 11—20关

11 逆向公转；12 双向节奏；13 移动接力；14 错峰通行；15 引力交会；16 逆向引力；17 宽路与窄路；18 开窗时刻；19 限时交会；20 顺风一跃。

逐关解锁，已通关可重玩，保留原有通关记录。验证新关卡：`node tests/next.cjs`。

## 21—30关

错峰窄道、逆向弧线、小型接力、短暂窗口、双星同行、风中落点、限时小目标、精准岔路、弧线交会、双星再会。25与30关同步双球，分别显示白色、蓝色预测轨迹，两球都抵达才通关。

验证：`node tests/third.cjs` 与 `node tests/twins.cjs`。双球验证覆盖固定间距、预览不修改状态、两球完整抵达及共同发射窗口。

## 星星与永久机会
第一关无限挑战；第二关起每关5次永久免费机会，首次起跳扣除，通关后无限重玩。每局40%概率出现一颗星，领取即保存，失败保留。5颗兑换当前关卡1次额外机会，无每日刷新。进度与钱包存于当前浏览器，清除数据或更换设备不共享。
