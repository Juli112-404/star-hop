# 行星行

单击起跳的 HTML5 星球游戏，支持桌面鼠标与手机触屏。当前提供五十个闯关关卡和无尽挑战，无后端、无外部资源。

## 下载试玩

根目录提供两个独立的离线 HTML，下载对应文件后用浏览器打开即可。两个版本的首页都提供「闯关」和「无尽」。

- [逐关探索版](index.html) 保留通关解锁和原有存档。
- [自由选关版](judge.html) 进入闯关后可直接选择 1–50 关，审核重试次数不限。可提交这份 HTML，也可用 `?level=31` 直达指定关卡。

两个版本共用关卡、机关和难度，分别保存进度和星星。

## 1—10关

1. 初次起跳
2. 两次跃迁
3. 斜掠窄口
4. 引力绕障
5. 横向接力
6. 90° 传送门
7. 风带绕行
8. 顺势接跳
9. 持钥开闸
10. 弹板借道

闯关以抵达终点为目标。随机出现的星星可兑换额外挑战机会，PERFECT 提供精准操作反馈。第一关显示点击引导，少数机关关卡有一句提示。桌面和手机都通过点按起跳。无尽模式提供计分、连击和本地最高纪录。

## 开发与验证

使用 Node.js 重建：`node build.cjs`。

运行验证：

```
node tests/review.cjs
node tests/mobile-size.cjs
node tests/minimal-ui.cjs
node tests/next.cjs
node tests/third.cjs
node tests/twins.cjs
node tests/economy.cjs
```

可选本机服务：`node server.cjs`，访问 http://127.0.0.1:8095 。

`src/review-data.js` 定义关卡，`src/levels-engine.js` 实现可独立测试的模拟，`src/review.js` 处理绘制和交互。`src/checkpoints.js` 管理落点续玩。

本地记录存储于浏览器，暂停菜单可导出试玩记录；不向服务器发送。已完成五十关路线、手机尺寸及界面自动检查，实体手机兼容性仍需实际试玩确认。

## 11—20关

第 12 关要在闸门打开时穿过，第 13 关要先落到移动中继开闸。第 15、16、20 关加入接力，分别利用引力、斥力和风场。第 17 关可走较窄的焚星捷径，也可走更宽松的三跳路线。

逐关解锁，已通关可重玩，保留原有通关记录。验证新关卡：`node tests/next.cjs`。

## 21—30关

第 21 关需要通过中继，第 22 关要预判绕圈移动的接力星球，第 24 关要在倒计时内赶上周期闸门。第 25、30 关同步发射双球，分别显示白色和蓝色预测轨迹，两球都抵达才通关。

验证：`node tests/third.cjs` 与 `node tests/twins.cjs`。双球验证覆盖固定间距、预览不修改状态、两球完整抵达及共同发射窗口。

## 星星与永久机会
第一关无限挑战；第二关起每关5次永久免费机会，首次起跳扣除，通关后无限重玩。支持拾星的关卡每次开局有50%概率出现一颗星，穿过星星并落到对应星球后保存。5颗兑换当前关卡1次额外机会，无每日刷新。进度与钱包存于当前浏览器，清除数据或更换设备不共享。

## 31—50关

第 31、45 关由入轨落点决定开哪扇门。第 31 关的两条路线分别直飞和借风，第 45 关可选两跳捷径或三跳接力。第 36 关的两跳分别用到两块弹板，第 48 关要在移动中继上等闸门开。

第 41、42、43、47、48 关可从最后一次安全落点重试。关内连续起跳不限次数。普通版重新挑战时，第一次起跳会消耗一次挑战机会。第 11、18、24 关的终点倒计时从开局开始，第 26、39 关从落到中继开始。飞行中超时也会失败。

第46关经弹板与两个中继三跳抵达终点，最后一跳需穿过感应环开闸。飞行时，球碰到实体挡板的边缘或圆端都会判定碰撞。第50关双球同一次起跳，可先后抵达终点。两条预测轨迹同时亮绿表示双球可以落在同一颗星球。

后段验证使用 `node tests/fourth.cjs`、`node tests/fifth.cjs`、`node tests/star-routes.cjs`、`node tests/retry-checkpoints.cjs`、`node tests/final-difficulty.cjs`。

## 无尽

落地的星球直接成为下一跳起点。前八跳为基础练习，星球逐渐缩小，间距逐步拉大。之后在基础跳之间穿插打乱顺序的机关。每成功落地得10分，星星仅进入无尽钱包，每段出现概率20%。花10颗无尽星星可从上一颗安全星球复活，保留本局分数。闯关与无尽的星星各自保存，新计分使用独立的无尽最高分记录。

无尽使用独立的布局数据。可以用 `node tests/endless.cjs` 验证连续落地、拾星、计分和复活，用 `node tests/editions.cjs` 验证两个离线版本的入口。
